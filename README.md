# auditwasm

Audit validation gates for wasm inputs before they hit prod.

**Site:** https://theworker02.github.io/auditwasm/

## Install / run

```bash
git clone https://github.com/theworker02/auditwasm.git
cd auditwasm
node src/cli.js
node --test
```
